# КМУ-2026 · Планировщик деловой программы

Интерактивный статический сайт деловой программы **VI Конгресса молодых учёных**
(2–4 декабря 2026, Санкт-Петербург, КВЦ «Экспофорум»).

Сделан как удобная надстройка над официальной программой: вся сетка мероприятий
в виде карточек в календаре по дням, фильтры, личный список и экспорт в календарь.

## Возможности

- **Календарь по дням** — два вида:
  - **Сетка** — временная шкала дня со всеми параллельными потоками (карточки
    расположены по времени начала и длительности, как в настоящем календаре);
  - **Список** — карточки, сгруппированные по таймслотам.
- **Избранное** — отмечайте мероприятия звёздочкой; список хранится локально
  в браузере (`localStorage`), без регистрации и сервера.
- **Конфликты по времени** — среди выбранных мероприятий автоматически
  подсвечиваются пересекающиеся таймслоты: бейдж на карточке, пояснение
  и сводный список конфликтов во вкладке «Избранное».
- **Google Calendar**:
  - по одному — кнопка «В календарь» на каждой карточке (прямая ссылка-шаблон);
  - все вместе — выгрузка `.ics` со всеми выбранными событиями (с напоминанием
    за 15 минут) и пошаговой инструкцией импорта в Google Calendar.
    Файл также подходит для Яндекс Календаря, Outlook и Apple Calendar.
- **Фильтры**: тематический трек, домен (медицина, ИИ, космос, атомная
  энергетика и др. — 16 доменов), формат, **спикер** (автокомплит по 802
  участникам), полнотекстовый поиск. Фильтры комбинируются.
- Карточка мероприятия: описание, зал, трек, все участники с должностями
  и аффилиациями, ссылка «Поделиться» (deep link `#event=…`).
- Адаптивная вёрстка (телефон/планшет/десктоп), печать, работа без интернета
  после загрузки страницы.

## Данные

Источник — официальная деловая программа Конгресса по состоянию на
**26.11.2026** (PDF, 82 страницы, 149 мероприятий, 802 участника).
PDF лежит в [`tools/source/`](tools/source/). Данные извлечены парсером
[`tools/parse_program.py`](tools/parse_program.py) в [`data.js`](data.js):
даты, время, залы, треки, названия, описания, спикеры с ролями.
Домены проставлены автоматически по ключевым словам (это неофициальная
разметка для удобства фильтрации).

> Программа может обновляться организаторами — сверяйтесь с
> [официальным сайтом](https://science-congress.com/).

## Запуск локально

Сайт полностью статический, без сборки и зависимостей. Достаточно открыть
`index.html` в браузере (данные подключены как `data.js`, поэтому `file://`
тоже работает). Либо поднять любой статический сервер:

```bash
python -m http.server 8080
# → http://localhost:8080
```

## Деплой на GitHub Pages

1. Создайте репозиторий и запушьте содержимое этой папки в ветку `main`:
   ```bash
   git init && git add . && git commit -m "КМУ-2026 планировщик"
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
2. В репозитории: **Settings → Pages → Build and deployment → Source:
   Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу
   `https://<user>.github.io/<repo>/`.

Все пути относительные, серверная логика не используется, файл `.nojekyll`
отключает обработку Jekyll — сайт отдаётся как есть. Обновление сайта =
новый коммит в ветку.

## Обновление программы

Когда организаторы выпустят новую версию PDF:

```bash
pip install pypdf
python tools/parse_program.py путь/к/новой_программе.pdf --out data.js
```

Парсер печатает статистику и аномалии; после обновления прогоните тесты:

```bash
node tests/test_core.js
```

## Структура

```

.nojekyll           для GitHub Pages
```

## Технические заметки

- Экспорт «все сразу» в Google Calendar реализован через `.ics`: у Google
  нет публичного URL-API для пакетного добавления событий, поэтому файл
  импортируется через *Настройки → Импорт и экспорт*. Одиночные события
  добавляются прямой ссылкой `calendar.google.com/calendar/render?action=TEMPLATE`.
- Время в `.ics` и Google-ссылках передаётся в UTC (МСК = UTC+3), поэтому
  события корректно отображаются в любом часовом поясе пользователя.
- Избранное и настройки вида хранятся в `localStorage` (`kmu2026.planner.v1`).
